# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and remember that many people here are practising on-call for the
first time. Asking "obvious" questions is the point of a gym.

To report unacceptable behaviour, contact the maintainer, [@soaresdiogo](https://github.com/soaresdiogo),
privately through GitHub. Reports are handled confidentially.
